# Stock Screener Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Build a Stock Screener page that filters stocks based on HAKA (Bandarmologi), Candlestick patterns, and Dominance.

**Architecture:**
- Frontend: New route `web-frontend/src/app/(app)/screener/page.tsx`.
- API: Create a new endpoint in `web-backend` to serve screened data.
- Backend: Logic in `agents/technical.py` and `agents/bandarmologi.py`.

**Tech Stack:** Next.js, FastAPI, PostgreSQL.

---

### Task 1: Create Backend API Endpoint for Screener

**Objective:** Create `/api/screener` that fetches/calculates metrics.

**Files:**
- Create: `web-backend/api/endpoints/screener.py` (assuming structure)
- Modify: `web-backend/main.py` (to include endpoint)

**Step 1: Define API contract**
- Inputs: filters (min_dominance, candlestick_type, min_haka_score)
- Output: List of stocks with scores.
